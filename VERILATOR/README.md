# 🔬 Open-Source EDA & ASIC Synthesis Flow

This directory contains the open-source Electronic Design Automation (EDA) flow for the **Intelligent Traffic Light Controller**. It provides high-speed cycle-accurate simulation, ASIC gate-level standard cell technology mapping, and structural schematic generation without requiring proprietary commercial licenses.

---

## 🎯 Why Open-Source EDA is Required
Open-source EDA tools provide unique advantages in semiconductor design and verification:
1. **High-Speed Simulation:** **Verilator** converts synthesizable Verilog directly into multi-threaded, cycle-accurate C++ executables, running orders of magnitude faster than traditional interpreted event-driven simulators.
2. **ASIC Gate-Level Synthesis:** Using **Yosys**, the RTL is synthesized and mapped directly into physical standard cells from the **OSU 0.18µm CMOS Library** (`osu018_stdcells.lib`), confirming the design is ASIC-ready.
3. **CI/CD Automation:** The entire simulation and synthesis pipeline runs headless in Linux/Docker containers and GitHub Actions with zero license servers or tokens.
4. **Transparent Waveform & Netlist Visualization:** Generates standard VCD traces for **GTKWave** and structural graphs via **Graphviz DOT** (`my_design_.dot`).

## 🛠️ Step-by-Step Execution Guide

### 1. Behavioral Simulation (Icarus Verilog + GTKWave)
To compile and execute the self-checking testbench:
```bash
# Compile RTL and testbench
iverilog -g2005 -o sim_traffic new.v new_tb.v

# Execute simulation
vvp sim_traffic
```
*Expected Output:*
```text
[ok]   next green P4 as expected
[ok]   next green P5 as expected
...
[ok]   reset test done
[ok]   illegal-state recovery done
served count P1..P6 = 338 349 335 348 340 334
*** ALL TESTS PASSED ***
```

To view the generated waveform trace:
```bash
gtkwave tb_traffic_fsm.vcd
```

---

### 2. Fast Cycle-Accurate Linting & Simulation with Verilator
To lint the design and check for synthesizability, race conditions, and width mismatches:
```bash
verilator --lint-only -Wall new.v
```

To compile a C++ cycle-accurate simulation harness:
```bash
verilator -Wall --cc new.v --exe sim_main.cpp
make -C obj_dir -f Vtraffic_fsm.mk
./obj_dir/Vtraffic_fsm
```

---

### 3. ASIC Standard Cell Synthesis (Yosys)
To synthesize `new.v` into real gates using the included `osu018_stdcells.lib`:
```bash
yosys -p "
  read_verilog new.v;
  hierarchy -check -top traffic_fsm;
  proc; opt; fsm; opt; memory; opt;
  techmap; opt;
  dfflibmap -liberty osu018_stdcells.lib;
  abc -liberty osu018_stdcells.lib;
  clean;
  write_verilog traffic_synth.v;
  show -format dot -prefix my_design_ traffic_fsm;
"
```
* **`traffic_synth.v`:** Contains the synthesized gate-level netlist containing D-flip-flops (`DFFSR`), NAND/NOR gates, and multiplexers.
* **`my_design_.dot`:** Contains the Graphviz graph of the synthesized netlist.

---

### 4. Visualizing the Netlist Graph (Graphviz)
To convert the generated DOT file into a readable image format:
```bash
dot -Tpng my_design_.dot -o my_design_schematic.png
# Or for vector format:
dot -Tsvg my_design_.dot -o my_design_schematic.svg
```
